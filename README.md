## Featured Project

### Tic-Tac-Toe AI — Minimax Algorithm

An interactive game built around an AI opponent that uses the Minimax algorithm to select optimal moves.

**What it demonstrates**

* Adversarial search and recursive decision-making
* Game-state evaluation and utility functions
* Python programming and application logic
* A browser-based interface using HTML, CSS, and JavaScript
* Project documentation and deployment with GitHub Pages
